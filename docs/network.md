# Ev ağı cihazları

Yönetim → **Ev ağı cihazları** sayfası ana menüde **Ev ağı** altında tüm giriş yapan kullanıcılara açıktır. Ağ taramasını yalnız yönetici yenileyebilir. macOS'ta `arp -an`, Linux/Raspberry Pi'de `ip -j neigh` komşu tablosunu okur. Linux'ta iproute2 ve ping (iputils) kurulu olmalıdır. Bu önbellek yalnız sunucunun gördüğü komşuları içerir; modemin bağlı tüm Wi-Fi/Ethernet istemcilerinin kesin listesi değildir. İzole/misafir ağındaki cihazlar görünmeyebilir.

**Ağ listesini yenile** özel IPv4/MAC kayıtlarını toplar, ilk 64 kaydı en fazla 4 eşzamanlı ping ile kontrol eder. Yanıt alınması erişimi doğrular; yanıt alınmaması çevrimdışı/kapalı olduğunun kanıtı değildir. Tam alt ağ port taraması yapılmaz. Kayıtlar `data/network.json` içinde 0600 izinle tutulur, Git'e gitmez. IP ile eşleştirilebilen panel cihazlarının adları gösterilir; eşleşmeyen kayıtlar için taranan ilk 64 IP adresinde sunucunun DNS çözümleyicisinden gelen cihaz adı (PTR kaydı) gösterilir. Ağ bir ad döndürmezse kayıt Tanımlanmamış olarak kalır. Üretici bulmak için MAC adresi üçüncü taraf servise gönderilmez.

Cihaz başına trafik/kullanım sayaçları bu sürümde yoktur. Bunun için modem/yönlendiricinin yetkili API, SNMP veya benzeri gerçek trafik verisi gerekir. Cloudflare hız ölçümü ev bağlantısının kısa örneklemidir, cihazların tükettiği veri miktarı değildir. Arayüz eksik sayaçları açıkça belirtir. Ağ yenilemesi cihazları açıp kapatmaz.
